# Contributing to Castvane Core

Use the pinned Rust toolchain and preserve the independent MIT implementation. Analyze client-visible behavior with a disposable reference instance. Add independently authored compatibility fixtures and describe any version or capability differences. Keep public API v3, configuration and internal cluster protocol versions independent.

Run the locked format, lint, test, release and smoke checks in [the release checklist](docs/PHASE_6_STATUS.md). Changes to media, IAM or consensus also need their corresponding integration suites. Test streams should be local and synthetic. Describe the configuration, tested platforms and evidence in the pull request. Keep credential material out of patches, test logs and example files.

Start with the [architecture and roadmap](IMPLEMENTATION_PLAN.md) and [deployment guide](docs/DEPLOYMENT.md). For security-sensitive reports, use the [security policy](SECURITY.md).
