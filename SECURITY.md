# Security policy

Castvane Core is preparing its first production release. The current development branch receives security fixes. Versioned support windows will be documented with the first accepted stable release.

Report vulnerabilities privately with **Report a vulnerability** on the repository's Security page when available. Include the build commit, deployment configuration with secrets removed, impact, and enough detail for maintainers to investigate. If private reporting is unavailable, use GitHub to contact the repository owner privately and request a suitable disclosure channel. Keep credentials, private keys, stream URLs and details of unpatched issues out of public issues. [Castvane Security](https://github.com/Castvane/core/security)

Refer to the [deployment guide](docs/DEPLOYMENT.md) and [phase status](docs/PHASE_6_STATUS.md) for isolation, backup and release limitations.
